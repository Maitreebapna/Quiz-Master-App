# Quiz-Master-App
Description 
Quiz Master - V1 is a multi-user exam preparation platform that allows users to take quizzes on 
different subjects and chapters. The administrator (Quiz Master) manages the quizzes, subjects, 
chapters, and users. The project ensures smooth quiz creation, user management, and score 
tracking. 

:-Technologies Used 
 Backend: Flask 
 Database: SQLite 
 Templating: Jinja2 
 Frontend: HTML, CSS, Bootstrap 
 Authentication: Flask-Login 
 Data Visualization: Chart.js 
 API Framework: Flask-RESTful

:-Purpose of These Technologies 
 Flask is used for handling web requests and routing. 
 SQLite is lightweight and sufficient for this application. 
 Jinja2 templating simplifies dynamic content rendering. 
 Bootstrap provides responsive and visually appealing UI. 
 Flask-Login ensures secure authentication. 
 Chart.js helps visualize quiz performance.

:-Implemented Features 
Default Features 
 Admin Panel: Create/edit/delete subjects, chapters, quizzes, and questions. 
 User Authentication: Register, login, and access quizzes. 
 Quiz Attempt & Score Storage: Users can attempt quizzes and view results. 
 Summary Charts: Uses Chart.js for data visualization. 
Additional Features 
 Bootstrap UI for better user experience. 
 Frontend validation using JavaScript. 
 Session management using Flask-Login.
